# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 2.3.x   | Yes       |
| < 2.3   | No        |

## Reporting a vulnerability

If you find a security issue in host-inspector, please report it privately rather than opening a public issue.

### How to report

1. Go to the Security tab on the GitHub repository and select "Report a vulnerability" to open a private advisory.
2. If private reporting is unavailable, email the maintainer directly through the contact details listed on the GitHub profile.

### What to include

To help evaluate and reproduce the issue quickly, include:

- The affected file or collector (for example, buffer boundaries in file streams or arithmetic logic).
- Step-by-step reproduction instructions or a minimal test environment.
- The Linux kernel version and distribution where the issue occurs.
- An assessment of the potential impact.

### Response timeline

- Acknowledgment: within 48 hours of receipt.
- Status updates: every 3 to 5 days while the issue is being investigated and patched.
- Resolution: if accepted, a fix will be published in a patch release. If declined, you will receive a detailed technical explanation.

Please do not publicly disclose the issue until a patch has been released.
